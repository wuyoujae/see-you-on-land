# 原创数字规律专项审核

交付 120 题，ID 为 `focus-number-001` 至 `focus-number-120`，全部标记 `sourceLabel: 原创专项练习，非真题`，`origin.isPastExam: false`。120 题的 `verification.status` 均为 `passed`。

| 范围 | 模块 | 数量 |
|---|---|---:|
| 数列 | 差分、倍数与递推、幂次、分数、交错、分组、数位 | 各 12，共 84 |
| 图阵 | 加减、乘除、复合运算 | 各 12，共 36 |
| 难度 | 基础 / 进阶 / 挑战 | 40 / 60 / 20 |
| 答案位置 | A / B / C / D | 各 30 |

`generate.py` 中的 84 个完整数列逐条独立编写，而非循环改几个参数扩充题数。覆盖 84 个具体结构，包括二阶作差、质数差、差的斐波那契关系、双项及三项递推、指数交替、分母作差、三路交错、拼数与数字平方和等。36 个图阵使用 36 种不同算术表达式，每题给 4 行完整例证，部分题反求输入位置；不是只给一行例证。

`verify.py` 使用精确 `Fraction` 运算，独立由规则推导数列全部非种子项；递推种子作为题干给定。图阵使用不同于生成表达式的等价逆向方程逐行验证。所有四选项分别代入，恰好一个成立。分数已约分且按数值检查重复，所有题干只隐藏一个数，表格值与审计值逐格一致。已逐条审阅数列解析和全部图阵完整行。

同时筛查常见替代规则：1–3 阶常差、等比、低系数仿射及双项递推、差的等比、两列简单交错、常见三项分组，以及所有同元图阵公式和小系数线性组合。没有其他选项在该规则库中成立；无需替换干扰项。有限项数列不可能对任意人为插值规则有绝对数学唯一性，因此这里的“唯一”指选项中符合常规、统一、可解释规律的唯一答案，不作无限规则空间的虚假承诺。

重点边界复核：

- 011 正负交替差，答案为 -2，零项不是缺失项。
- 041 分子与分母各自递推，精确答案 34/89。
- 046 分母 n²+3，避免将分母常差和原分数常差混淆。
- 053 三列交错，问号只补第三列。
- 072 分组中的组号平方只出现在解析，题干不提示规则。
- 082 10890 倒序为 9801，保留前导零的数值含义正确。
- 095 隐藏第三输入，0 只是干扰项，独立方程唯一确定 2。
- 112 平方差非单调，隐藏输出，避免反求输入时正负双根。
- 113 平方输入反求使用正整数候选，唯一解为 24。
- 117–120 含四输入运算，使用五列表格且有四行完整例证。
