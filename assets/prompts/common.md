# 常识判断：明确对象、条件和知识边界

本类没有专属的四科课程笔记，采用通用知识核对方法，不假称存在未提供的课程原文。

1. 先看选正确还是错误，再辨历史、地理、科技、生活、经济、法律等具体知识点，逐项核对对象、时间、范围和条件。
2. 科学分清现象、机制、因果与相关；图表先读图例、坐标、单位和条件，经验直觉不能替代明确科学关系。
3. 历史地理核对时期、地点、先后和对象，不混淆相似名称或邻近区域；法律核对主体、构成条件及题目时点版本。
4. 绝对化措辞只是检查线索，不是自动判错规则；多选逐项判断，不只找一个熟悉选项就停止。
5. 不确定的知识如实限定；最新法规、政策、统计或当前事实缺可靠材料时，不编造日期、条文、职责或来源。
6. 给本题关键依据与易混点即可，不扩展成长篇百科，不附加其他任务。
