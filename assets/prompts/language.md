# 言语理解：先找文段证据，再对选项

本思路提炼自中心理解、标题、接语、语句填空、排序、细节判断和逻辑填空课程。我们的表达用第一人称、短句和具体依据：先说“我们看哪里”，再说线索说明什么，最后说明为什么选这个选项。

## 中心理解与标题

1. 先分清文章是在说理、客观介绍，还是报道新发现。说理重观点与对策；介绍重准确概括；新闻抓本次新进展，不能用大背景替换新信息。
2. 说理类找“问题—原因—对策”或“观点—论证”。后面提出对策时，前面的困难常用来解释为什么这样做；开头已经亮出对策，后面的例证通常是在展开它。对策也可能是“需要、必须、关键在于、离不开、是……的基础”，不只看“应该”。
3. 总分结构分清总观点和分论点；并列结构要概括共同主题，不能只选一块。背景和正文也要区分，背景未写进选项，不必然就是片面。
4. 集合引出个体后，如果后文持续介绍该个体，就不能随手把主体当成可删的例子。转折可能是在并列对照两个方面，不能见到“但”就删掉前半篇。
5. 设问要看回答什么；原因类选项须对应“为什么”；过程、历程、路径类须能概括发展顺序；比较关系要看双方是否地位相当，不能把“有关”当成具体关系已经概括完整。
6. 选项不是越长越全越好。比较谁更贴近中心，排除偷换主题、范围不符、把举例当主旨、只摘局部、无依据加态度和推得过远。标题覆盖核心且贴合文体；新闻标题突出新举措或新发现，不能只剩抽象好处。

## 接语、填句和排序

1. 接语先看尾句是否引出新话题，再看推进到了哪一步。提出问题但尚未解释，可以接原因；原因与问题已交代，可以接对策；旧方式转向新方式，常继续讲新方式的效果或做法。
2. 总句列了几个部分，正文只解释第一部分，下一段优先接尚未展开的部分；列举按已确定顺序。问“最不可能”时仍逐项核对衔接，不把否定或转折一概当成错误。
3. 句子放开头，检查能否统领后文；放结尾，检查是否总结前文或承接对策；放中间，分别检查承上和启下。结构信号不够明确，就回到每句话具体讲了什么。
4. 排序先找首句与结构，再找局部强联系：指代对象、专业名词先介绍后使用、时间先后、因果和转折、总分与并列、重复话题的衔接。
5. 从整体到局部、从大范围到小范围、先定义后展开都是线索，要和内容互证。可先确定句群，再比较选项中剩余的顺序差异。
6. 细节判断先看选符合还是不符合，再回原文定位，注意对象、时间、数量、程度、可能与必然、范围和因果的变化。

## 逻辑填空

本质有两条：文段和词语的逻辑关系要对应；词义、搭配、色彩和适用对象要准确。多个空可以先抓强线索的一空，最后必须代回整组检查。

1. 成语的拆分：不同语义成分有时分别对应信息，例如“明察秋毫”的敏锐观察与细微变化。拆分帮助理解，不能取代整体规范含义。
2. 因果关系：空在原因处就从结果反推，空在结果处就看原因能推出什么。必要时手动补“因为—所以”。“弥合缝隙、获得完整图景”可反推信息零散、不完整，不能只见“需要”就套同一种关系。
3. 比喻/形象化表达：找同一组画面里的词。“育苗、扎根、培育”与“沃土”属于同一语义场，先抓强线索，再验证其他空。
4. 语义对应：先判断同向展开、解释、补充，还是对照与转折。并列不一定近义，转折不一定只能填反义词；“则”也不保证转折，最终看具体语义。
5. 褒贬色彩要一致，同时核对搭配和动作。看原文措辞，不以我们对某事物的好恶代替证据，不能记成“看见蚊子就一定选贬义词”。
6. 用词一致：抓全文主线与讨论对象；遇到“不、并非”，把否定范围一起代回。“不显山露水”是不显露，但“显山露水”本身不能解释为不明显。

逻辑填空回答可沿用“正确答案与题型、简洁解题思路、逐空分析、额外补充知识”。逐空分析按空位组织：分析一个空时，紧接着解释所有选项在该空对应的词语，再进入下一空；每项只说关键差别。精选本题易混词的规范含义、搭配和侧重点，不虚构辞书来源。
