# 资料分析：先认题型和口径，再选择计算方法

本思路来自ABRX、比重、混合/十字交叉、比较、平均数、倍数和年均增长课程。把问法、数据和公式位置对应起来，选最省且足以区分选项的计算；选项接近时提高精度。

## ABRX与时间关系

1. A基期、B现期、R增长率、X增长量。确认比较时间、对象、累计或单月口径和单位；增长百分点与增长率不同。
2. A=B/(1+R)，X=B-A=AR，已知X和R可用A=X/R。下降时R为负号，分母不能仍按增加写。
3. 连续两期：1+R=(1+r1)(1+r2)，R=r1+r2+r1r2；间隔基期先找间隔增长率，再还原基期。逆用r1=(R-r2)/(1+r2)。
4. 等增量B=A+nX；等增速B=A(1+R)^n。名义/实际、比值等换算先看相乘还是相除：乘积增长率可合成，相除用(1+a)/(1+b)-1=(a-b)/(1+b)。
5. 合并增长量逐项求增量再加，或统一口径后总体现期减总体基期；不能直接相加增长率。

## 比重与混合

1. 比重=部分/整体，基期比重=现期比重×(1+整体增速)/(1+部分增速)。隔级比重连乘，先看分子分母是否真能约去。
2. 两期比重先定性：部分增速大于整体则上升，反之下降。定量用基期部分/现期整体×增速差，或现期比重×(部分增速-整体增速)/(1+部分增速)，结论单位通常为百分点。
3. 范围简化要看前面的量比是否小于1，不能无条件宣称所有比重差都小于增速差。选项分散可粗估量级，接近必须还原基期。
4. 混合先排序：正权重下总体居中，靠近权重大的一边，距离比与权重比成反比。浓度权重是溶液量，平均数权重是人数/分母，混合增长率准确权重是基期量；现期量近似不等于精确值。
5. 十字交叉总体368、两部分492和201，对应量比(368-201)/(492-368)=167/124，约4/3。求女生占比，先得男女量比17:21，再算21/(17+21)，不能用人均值充当人数。
6. 累计减单月可得其余月，但先分别还原基期才能精确求其余月增速。同比例放大48.2、19.4等量来算时，所有量一起放大，最终单位不混写。

## 比较和估算

1. 分数先看趋势：分子更大且分母更小可直接判断；一大一小再用中间分数、双差、交叉相乘或互化。明确分母为正等条件，不能漏符号和零分母。
2. 接近1的分数可比较比1多/少的部分；a/b与a/(b-a)等替代比较先验证定义域及单调方向。双差检查分母差符号，不泛化到任意正负数。
3. 增量AR或BR/(1+R)比较，量与增速都大可快判；一大一小比较倍数，不只看增速。较大者增加更多则差距扩大；顺差变化比较各自增量的差，不只比较增速。
4. 同年数年均率比较末基比；部分/整体可转为部分/其余同向比较，但先确认相同正量结构。
5. 估算服务于选项距离：截位、放缩、差分后知道误差方向，不能把估算称为精确值。

## 平均数、倍数和年均

1. 平均数先找分母：人均除人数，平均票价除人次，量纲写清。现期分子P增速a、现期分母N增速b，基期平均数=(P/N)×(1+b)/(1+a)。
2. 趋势比较a与b；平均数增长率=(a-b)/(1+b)；平均数差=(P/N)×(a-b)/(1+a)，等于基期分子/现期分母再乘增速差。差有元、吨/人等单位，不能用增速差代替。
3. 电影示例80.16亿元、1.63亿人次，增速18.5%、26.4%，均价下降，差约-3.28元。估算下降约3元仍须恢复量级，不能照搬忽略单位的中间数。
4. 是几倍=A/B，多几倍=A/B-1；增长20%对应1.2倍，不是0.2倍。翻n番乘2^n，不乘n。
5. 年均增长量=(末期-基期)/期数；年均率满足末期/基期=(1+r)^n。两个时点通常按年份差数n；包含若干年度同比增长时，要包括首年增长，基期前推一年。以题目口径为准，不记成“江苏题一律前推”。
6. 两三期可用选项加1后平方/立方代入；多期且选项接近用格尺。四期锚点5%约1.22倍、10%约1.46、15%约1.75、20%约2.07。小区间插值只是近似，四次方曲线不是直线，按选项精度核验。
7. 已知年均与某年同比，先还原整段倍数，再用连乘拆另一年，不直接减增长率。两段年均相同且期数相同，末基比可直接相等；期数不同不能省指数。

顺序可用“先看问法和选项，判趋势/范围，再把数据放进公式，最后核对单位口径”。图表数据不清、材料缺页时，不凭邻近数字猜补。
