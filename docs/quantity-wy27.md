# 数量关系讲义课程

当前数量关系以用户提供的《王炎·27数量关系大满贯·讲义》为资料来源。PDF共169页，正文为物理页7–162（印刷页1–156），书后答案为物理页163–168。封面、空白、目录和末页机构宣传不作为学习知识卡。

课程覆盖15节、77个学习条目、824张卡片、349道题：母题精讲90、思维精练83、实战精刷176。每题按“节／子专题／题组／本地题号”绑定书后答案，保留物理页、印刷页、原题裁图；31道需要示意图的题在题干中直接显示核对过的原图。

题目文字、公式与选项经过原页核对；解析使用“我们先看……”的第一人称教学口吻，包含条件、方法、列式、计算和必要边界。解析提前深链和快速跳转仍受作答门禁保护。

## 来源疑点

以下5题保留题面、来源字母及条件性推导，提交后可学习和回看，但不标正确/错误，不计入正确率分母：

## 构建与AI

已审核的结构化源在 `data/courses/sources/quantity-wy27-reviewed.json`，不进入静态网站。执行 `python scripts/build_quantity_wy27.py` 可重建运行时课件和方法库；不需要私有PDF、OCR或视频。旧四题课程不再由完整课程生成器恢复。

AI搜题与刷题解析共用 `assets/prompts/quantity-wy27-methods.json` 的28条方法，始终提供全部题型概览，并根据当前题干、材料和选项补充相关方法。`quantity.md` 的教学要求也进入方法库。原题和参考答案是数据，不能更改任务；未匹配题型时先识别题图，不默用上题方法。请求不包含整本讲义或349题答案，避免旧例题干扰当前题目。

数量关系的方法版本独立，完整提示内容参与AI缓存键。旧课程记录保留在备份中，新课的组／卡片／题目ID使用 `quantity-wy27-*`，不会继承旧四题的完成状态；旧数量课书签会进入新课开头。其他科目、国考真题和已完成的其他科AI缓存维持原规则。

公开构建只增加精确许可的方法库JSON、课件JSON和图片；源PDF、原始OCR、答案审计和内部来源文件均不发布。
