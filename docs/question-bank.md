# 国考与广东省考行测题库及来源说明

范围为2014—2026年国考与2017—2026年广东省考《行政职业能力测验》。共45套卷、5423个已收录卷内题次、3810条题库记录。国考原有30套、3965题次、2580条记录保持不变；广东新增15套、1458题次、1230条记录。跨卷出现关系保留在paperRefs；原qid相同且题面一致的题，以及题面、选项与答案完全一致的补题合并存储。早年来源单独编号，未强行合并异序选项。

六大类为政治理论、常识判断、言语理解、数量关系、判断推理、资料分析。题干、选项、材料、来源答案与来源解析分字段保存；题图、公式图和早年解析裁图均已本地化。

## 可追溯来源

- [ERRRC/xingcezhenti](https://github.com/ERRRC/xingcezhenti)：2016—2026年国考分模块原题、答案、解析和本地图，固定提交记录在每题source.repoCommit。
- [AdministrativeAptitudeTest](https://github.com/Yaoyuan-Zhang319/AdministrativeAptitudeTest)：2014/2015原题与参考答案PDF，以及2022副省级补缺题的独立PDF依据；每题链接精确到文件与页码。
- 对照资料的具体网址保留在相应题目的source、sourceAnswer与alternativeReferences中。

公开整理、网友回忆及机构参考答案均如实标注。上游即使称“官方解析”，本平台也统一标为“公开整理题库参考答案”，不把整理版说成主管机关公布答案。

## 已处理的资料问题

- 补齐2022副省级来源遗漏的原卷第4题及两幅历史照片。
- 将两道误入资料分析的独立数学题归回数量关系，并去掉不属于它们的材料。
- 限定真实材料组边界，保留段内公式与划线文字。
- 2014年第6、19、94题存在不同来源参考答案，显示提示与其他参考链接，来源答案字段保留所列PDF键。

2016年以后的套卷按六大类及来源模块内顺序编排；补缺题放在对应大类末尾。界面称“来源编排”，未把整理后的模块号冒充原卷全局题号。2014/2015保留经原卷PDF核对的题号。

## 运行时数据与检查

入口为data/question-bank/manifest.json；subjects/保存六科题目，papers/保存每套卷的题目ID与科目计数。每题在作答前仅渲染题面，提交后才渲染来源答案与超级思维解析。

可执行 `python -m unittest discover -s tests -p test_question_bank.py` 检查全部年份卷种、逐卷题量、题目索引、答案键、材料图片、正反卷关系及已知资料修正。原始PDF、下载审计和研究缓存留在tmp/national_exam_research，不进入网站。

## 按课程模块刷题

判断推理1204题分17个模块：现有12个逻辑课程组，外加图形推理、定义判断、类比推理、科学推理、归纳推理。数量关系441题分20个模块：现有15个王炎课程组，外加数字推理、周期与日期、统筹与数学推理、植树与间隔、基础计算。所有题均有唯一主模块；补充模块不伪造课程链接。

分类按完整题意与解析核对，课程同题优先遵循课程归属；修正了57道广东判断题的上游小类误标。scripts/question_modules保存分类规则及绑定题面哈希的审核映射，变更或新题须重新复核。每题topicId和classification记录归属与依据，manifest中modules.questionCount按实际题目计算。

“做题”→科目可组合选择考试、试卷、模块；模块选项显示当前来源下真实题量。选定模块后切换来源，即使交集为空也保留模块并禁用开始按钮，不自动换到其他模块。按试卷练习也能进一步选科目和模块。本轮topicId、固定题序、草稿与提交结果沿用已有会话备份机制；旧记录兼容保留。

有对应课程的模块可点击“学习这个模块”回到学习板块。课程内容本身未改写。

- [2020县级原题与答案](https://gwysydw.com/bs/dqgwy/news_73532.html)及[2020乡镇原题与答案](https://gwysydw.com/bs/dqgwy/news_73544.html)：六个数字推理题次补缺。
- [独立PDF集合](https://github.com/Yaoyuan-Zhang319/AdministrativeAptitudeTest/tree/1896de17764058dc1199d668edbf9f7e96cbc77a)：复核缺题与原卷结构。

审核过的补题、科学推理重分类与缺口保存在scripts/question_sources，不随静态站点公开资源包递归发布。原始网页、PDF和研究审计留在tmp/guangdong_exam_research。仅首次离线重建需要下载原始资料与requirements-knowledge.txt中的解析依赖；网站部署直接使用已审核JSON和本地图。

```powershell
python scripts/download_guangdong_exams.py
python scripts/import_guangdong_exams.py --write
python -m unittest discover -s tests -p "test_question*.py"
```

只重建国考的旧import_national_exams.py会生成国考基础库，随后应运行上述广东合并器恢复广东卷和两科模块分类；不要发布中间结果。合并器的写入前检查要求题干、选项、答案、图片、计数差额和全部模块均可核对。
